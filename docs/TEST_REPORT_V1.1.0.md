## 3. 자동 테스트 범위

- 키 파싱: A~Z, 0~9, F1~F24, 조합키, 한글 별칭
- 키 오류: 중복키, 미지원키, Ctrl+Alt+Delete
- 시간: 50초와 상·하한 경계값
- 키 누르기: Space 10초와 취소 시 안전 해제
- 마우스: 현재 위치·고정 위치·좌·우·더블·휠
- 반복: 횟수 반복 및 지정 시간 연속 클릭
- 문자: 한글·유니코드·Enter·Tab·입력 간격
- 저장: 스키마 v2 왕복과 v1 호환
- UI: 모든 주요 버튼 Click 핸들러와 동작 메뉴
- 디자인: Primary·Danger 버튼 흰색 글자 계약
- 빌드: 버전, warnings-as-errors, 단일 EXE

## 4. CI 품질 게이트

실행 순서:

1. 애플리케이션·테스트 프로젝트 복원
2. 애플리케이션 Release 빌드, 경고를 오류로 처리
3. 테스트 하니스 Release 빌드, 경고를 오류로 처리
4. 자동 회귀 테스트 실행
5. win-x64 self-contained single-file publish
6. EXE 존재 확인
7. ZIP·SHA-256 생성
8. 검증 산출물 업로드

## 5. 실행 결과

CI 완료 후 다음 항목으로 갱신한다.

- 자동 테스트: 대기
- 애플리케이션 빌드: 대기
- 테스트 빌드: 대기
- 단일 EXE publish: 대기
- ZIP 생성: 대기
- SHA-256 생성: 대기
- 최종 판정: 대기

## 6. 수동 인수 테스트

자동화가 실제 외부 프로그램의 입력 수용을 완전히 대체할 수 없으므로, 배포 후 제품 소유자가 다음을 확인한다.

- 메모장 문자 입력
- Ctrl+C·Ctrl+V
- Space 10초 유지
- 현재 위치와 고정 좌표 클릭
- 연속 클릭 실행·중지
- 동작 메뉴 반응
- 색상 버튼 글자 표시
- 50초 대기 표시·저장·불러오기

## 7. 잔여 위험

- 대상 프로그램이 관리자 권한이면 동일 권한이 필요할 수 있음
