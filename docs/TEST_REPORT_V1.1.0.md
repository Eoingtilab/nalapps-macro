## 6. 발견·수정된 테스트 인프라 결함

### TINF-001: 테스트 프로젝트 참조 실패

- 현상: self-contained WPF 실행 프로젝트를 non-self-contained 테스트 실행파일이 참조하여 `NETSDK1151` 발생
- 조치: 테스트 프로젝트를 동일한 `win-x64` self-contained 구성으로 정렬
- 재검증: 애플리케이션·테스트 빌드 모두 경고 0, 오류 0

### TINF-002: 연속 클릭 테스트 경계 불일치

- 현상: 실행 엔진 단위 테스트의 350ms 시나리오가 사용자 UI의 초 단위 검증과 충돌
- 조치: UI는 1초 단위를 유지하면서 엔진·저장 모델은 10ms 이상 연속 실행을 검증하도록 규칙 분리
- 재검증: 연속 클릭 시간·간격 테스트 PASS

### REL-001: 마우스 입력 신뢰성 보강

- 기존 `mouse_event` 중심 처리 대신 키보드와 동일하게 확인 가능한 `SendInput` 경로로 통합
- 전송 개수가 요청 개수와 다르면 실행 오류로 보고
- 중지·종료 시 왼쪽·오른쪽 마우스 버튼 해제

## 8. 수동 인수 테스트 필요 항목

자동 테스트는 실행 명령과 상태 전이를 검증했지만, 실제 외부 프로그램이 Windows 입력을 받아들이는지는 제품 소유자 PC에서 확인해야 한다.

1. 메모장에 한글·영문·여러 줄 문자 입력
2. Ctrl+A, Ctrl+C, Ctrl+V
3. Space 10초 유지 후 정상 해제
4. 현재 위치 왼쪽·오른쪽·더블클릭
5. 고정 좌표 클릭
6. 10회 반복 클릭
7. 10초 연속 클릭과 Ctrl+Alt+F12 긴급 중지
8. `동작` 버튼 메뉴 표시
9. 파란색·빨간색 버튼의 흰색 글자 표시
10. 50초 대기 저장·불러오기
